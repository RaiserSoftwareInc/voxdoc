Vox API Reference

The https://api.voxformat.dev/v1 API provides programmatic access to create, validate, compile, and manage Vox documents. All endpoints accept and return JSON. This reference covers authentication, available endpoints, and code examples in multiple languages.

ℹ️ Base URL
https://api.voxformat.dev/v1 All endpoints accept and return JSON. Authenticate with a Bearer token in the Authorization header.

Authentication

All API requests must include a Bearer token in the Authorization header. Tokens are issued through the developer dashboard and expire after 90 days. Each token is scoped to a specific organization and set of permissions.

⚠️ Keep Your API Keys Secure
Never expose your API token in client-side code, public repositories, or logs. Use environment variables or a secrets manager to store tokens. If a token is compromised, revoke it immediately from the developer dashboard.
auth-example.sh
# Set your API token as an environment variable
export VOX_API_TOKEN="your-token-here"

# Make an authenticated request
curl -H "Authorization: Bearer $VOX_API_TOKEN" \
     {{base_url}}/{{api_version}}/documents

Create a Document

Send a POST request to /documents with a JSON body containing the document metadata and initial blocks. The server assigns an ID and returns the created document.

const response = await fetch('{{base_url}}/{{api_version}}/documents', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.VOX_API_TOKEN}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    title: 'My Document',
    description: 'A new Vox document',
    blocks: [],
  }),
});

const doc = await response.json();
console.log('Created document:', doc.meta.id);
import os
import requests

response = requests.post(
    '{{base_url}}/{{api_version}}/documents',
    headers={
        'Authorization': f'Bearer {os.environ["VOX_API_TOKEN"]}',
        'Content-Type': 'application/json',
    },
    json={
        'title': 'My Document',
        'description': 'A new Vox document',
        'blocks': [],
    },
)

doc = response.json()
print(f'Created document: {doc["meta"]["id"]}')
curl -X POST {{base_url}}/{{api_version}}/documents \
  -H "Authorization: Bearer $VOX_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "My Document",
    "description": "A new Vox document",
    "blocks": []
  }'

Compile a Document

The compile endpoint validates the document, checks accessibility requirements, resolves variables, and generates self-contained HTML. The response includes the compiled HTML and any warnings encountered during compilation.

const response = await fetch(
  '{{base_url}}/{{api_version}}/documents/doc-id/compile',
  {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.VOX_API_TOKEN}`,
    },
  }
);

const result = await response.json();
if (result.success) {
  // Write the HTML to a file
  fs.writeFileSync('output.html', result.html);
}
import os
import requests

response = requests.post(
    '{{base_url}}/{{api_version}}/documents/doc-id/compile',
    headers={
        'Authorization': f'Bearer {os.environ["VOX_API_TOKEN"]}',
    },
)

result = response.json()
if result['success']:
    with open('output.html', 'w') as f:
        f.write(result['html'])
curl -X POST {{base_url}}/{{api_version}}/documents/doc-id/compile \
  -H "Authorization: Bearer $VOX_API_TOKEN" \
  -o output.html

Getting Started

  1. 1
    Create an account and get your API token

    Sign up at the Vox developer dashboard and navigate to Settings > API Tokens. Click Generate Token, give it a descriptive name, and copy the token value. Store it securely as an environment variable.

  2. 2
    Install the SDK for your language
    # JavaScript / TypeScript
npm install @vox/sdk

# Python
pip install vox-sdk
  3. 3
    Create your first document via the API

    Use the POST /documents endpoint to create a new document. Add blocks using PUT /documents/:id and then compile the result using POST /documents/:id/compile.

  4. 4
    Validate and compile

    Before publishing, always validate your document with POST /documents/:id/validate to ensure all accessibility requirements are met. Then compile to HTML and verify the output renders correctly.
