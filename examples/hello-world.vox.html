Welcome to Vox

Vox is a structured document format designed to replace static PDFs with accessible, interactive, and machine-readable documents. Every Vox document is a JSON file that can be validated, compiled to HTML, and reviewed collaboratively.

💡 Getting Started
You can create your first Vox document in under a minute using the CLI. Just run vox init and start adding blocks.
terminal
# Install the Vox CLI globally
npm install -g @vox/cli

# Create a new document
vox init my-document

# Add some content
vox add heading --content "Hello World"
vox add paragraph --content "This is my first Vox document."

# Validate and compile
vox validate my-document.vox
vox compile my-document.vox --output my-document.html

Why Vox?

Traditional PDFs are opaque binaries that resist search indexing, accessibility tools, and programmatic manipulation. Vox solves these problems by storing documents as structured JSON with semantic block types, built-in accessibility metadata, and a compilation pipeline that produces standards-compliant HTML.

Frequently Asked Questions

What is a block?

A block is the fundamental unit of content in a Vox document. Each block has a type (such as heading, paragraph, code, or table), a unique identifier, and type-specific properties. Blocks can be nested inside container blocks like accordions, tabs, and steps.

How does Vox handle accessibility?

Accessibility is a first-class concern in Vox. The compiler enforces that all images have alt text, all diagrams have descriptions, all tables have summaries, and all math blocks have spoken text. The compiled HTML includes ARIA attributes, skip navigation, semantic elements, and responsive CSS that adapts to any viewport or assistive technology.

Can I convert existing PDFs to Vox?

Yes. The Vox MCP server can assist with converting existing documents by extracting structure, generating block content, and flagging areas that need human review. The conversion process preserves as much semantic meaning as possible and marks low-confidence sections for verification.
